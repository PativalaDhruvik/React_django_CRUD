# 📚 BookStore CRUD Application

A simple **CRUD (Create, Read, Update, Delete)** application built with **Django REST Framework (backend)** and **React (frontend)**.  
This app allows you to manage a list of books with their title and release date.

---

## 🚀 Features
- **Create**: Add new books with title and release date.
- **Read**: View all books in a list.
- **Update**: Edit existing book details.
- **Delete**: Remove books from the list.
- RESTful API built with Django REST Framework.
- React frontend with hooks (`useState`, `useEffect`).

---

## 🛠 Tech Stack
- **Backend**: Django, Django REST Framework
- **Frontend**: React (Vite or CRA)
- **Database**: SQLite (default, can be swapped for PostgreSQL/MySQL)
